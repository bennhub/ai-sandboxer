Test Code Dojo

AI-powered QA code practice using local Qwen coder.

Train automation coding, code review, test design, and AI workflow skills in one local-first dojo built around Qwen2.5-Coder.

The AI features run entirely on your own machine — nothing is sent to a server. To use them:

  1. Download and install Ollama.
  2. Download the Qwen2.5-Coder model by running ollama pull qwen2.5-coder:7b in a terminal.
  3. Keep Ollama running in the background, then use the AI features on this site.
